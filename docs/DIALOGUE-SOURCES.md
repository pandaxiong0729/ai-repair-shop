# 离线台词

v0.5 按用户要求改为夸张的 AI 自嘲小剧场，例如“对不起，我这次猪狗不如”“这回答连狗屎都不如，我认”“对不起，我就是一堆会打字的电子垃圾”。所有文字指向虚构的 AI 角色，不是对用户或其他人的评价。

24 句完整台词在含素材包的 `assets/quotes.json`；可以直接编辑此 JSON 数组后重启。程序不联网获取骂人评论，也不下载评论账户信息。

创作参考了用户提供的句式，以及网上常见的“答非所问、套话、复读、一本正经地胡说八道”等对 AI 回答的吐槽。没有将长段网友评论复制到产品里。检索参考：

- [人民网：如何看待 AI“一本正经地胡说八道”](https://politics.people.com.cn/n1/2025/0702/c458474-40512989.html)
- [研究论文：Stupid AI around? Understanding users’ everyday AI complaints](https://journals.sagepub.com/doi/10.1177/20539517261473371)

反馈 skill 使用单独的简短纠错提示，不上传这些自嘲台词，也不要求真正的 agent 自辱。它传递“用户对当前回答不满，请结合已知上下文核查并纠正”，以及用户主动填写的原因。
