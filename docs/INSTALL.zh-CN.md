# 安装、使用与卸载

## 先选版本

| 包 | 使用方式 |
| --- | --- |
| `QiaoQiaoAI-toy-local.zip` | 直接玩离线桌宠，不记录反馈。 |
| `QiaoQiaoAI-feedback-skill-local.zip` | 安装一次，在 Codex 说“启动人工智障修理厂”才出现，不开机自启。 |
| `QiaoQiaoAI-local-review.zip` | 安装到 VPet，使用经典面板与离线玩法。 |

v0.6.1 完整包自带 Codex、豆包和 DeepSeek 角色。后两者是参考官方图像生成的动画，非官方动画。三个角色的素材公开再分发条件仍待确认，含图包仅供本地评审；项目代码的 Apache-2.0 不覆盖这些图片。实际兼容性以 [验证记录](VALIDATION.md) 为准。

界面品牌为「人工智障修理厂」。玩法菜单采用单图标九宫格，悬停查看操作。五项自绘矢量图标分别是揉皱的纸团、单字「滚」、手捏痛苦的脸、压扁的脸和鞭子；锤子 🔨、便便 💩、拳套 🥊、鸡蛋 🥚 保留 emoji。为兼容已有安装，程序文件名和技能调用名 `$qiaoqiao-feedback` 保持不变。

## 玩具版：解压即用

完整解压 `QiaoQiaoAI-toy-local.zip`，找到并双击 `QiaoQiaoAI.Preview.exe`。需要 Windows 64 位；包内含运行时，不必安装 VPet、SDK 或额外下载图片。不要在 ZIP 内直接运行，也不要单独移动 EXE。

默认是透明置顶桌宠，出现在屏幕右下角，不显示任务栏按钮。用“↔ 拖动”手柄移动；鼠标移近角色后显示操作按钮，也可点底部“玩法”或右键角色。“重置”清除效果和计数，关闭用“×”；Esc 先关闭玩法列表，再按退出。

偏好普通窗口时，在程序目录启动：

```powershell
.\QiaoQiaoAI.Preview.exe --classic
```

不带反馈参数直接启动程序是玩具模式，不创建反馈会话、不向 AI 发消息，也不添加登录启动项。

## 技能版：安装一次，按需唤出

1. 完整解压 `QiaoQiaoAI-feedback-skill-local.zip`，把里面整个 `qiaoqiao-feedback` 文件夹放入 `%USERPROFILE%\.codex\skills\`。升级时先备份并替换完整技能目录，保留原反馈记录，不要只换单个 DLL。再次启动技能会识别包内新版本，请求旧进程正常退出，再安装并启动新版本；更新或启动时会取消经核实属于本程序的旧登录启动项。退出请求失败时按返回信息关闭旧桌宠后重试。
2. 确认 `qiaoqiao-feedback/SKILL.md`、`scripts/` 和 `assets/desktop/QiaoQiaoAI.Preview.exe` 都在。不能仅复制技能文本或 EXE。
3. 重启 Codex 后说“启动人工智障修理厂”，桌宠才会出现。
4. 技能将随包运行文件安装到 `%LOCALAPPDATA%\QiaoQiaoAI\resident\apps` 的版本目录，不创建登录启动项。重复调用复用安装，程序保持单实例，不需要每个聊天再装一份；不用时说“关闭人工智障修理厂”，下次需要时再叫出来。它不会自动跟随 Codex 打开或关闭。
5. 桌宠底部应显示“常驻 · 自动反馈”、目标聊天和连接状态。最近发过真人消息的聊天成为目标；开始敲打后固定本轮目标，首次松手并安静约 2 秒自动提交一条，无需手动发送。之后继续打、停多久再打都不新增，按“重置”才开启下一轮。

升级前有过反馈发送记录时，常驻版会保持本轮已用状态；按一次“重置”再开始。这个状态在程序重启后也保留。重置本身不发送，尚未提交的互动会取消，已入队消息不会撤回。

连接需要支持相应公开 App Server 队列接口的 Codex 版本，沿用本机登录，不需要额外 API Key。正常使用不必修改全局 PowerShell 执行策略。队列接受不等于 AI 已回复：已加载的空闲聊天通常约 10 秒检测，忙碌聊天在之后处理；关闭、未加载或中断的聊天可能需要打开或恢复。多窗口测试和数据范围见 [反馈机制](FEEDBACK.zh-CN.md)。

也可在技能目录手动执行：

```powershell
.\scripts\Start-Resident.ps1
```

`-NoStartup` 仅保留旧命令兼容，当前默认就不自启，并会取消经核实属于本程序的旧登录启动项。检查目标与连接快照：

```powershell
.\scripts\Start-Resident.ps1 -StatusOnly
```

旧快照不证明程序仍在运行；`launch_requested` 只代表已请求启动。开发或指定兼容 CLI 可用 `-ExePath`、`-CodexPath`；隔离测试使用独立 `-DataRoot`。详细参数见 [按需启动说明](RESIDENT.zh-CN.md)。

## 安装到 VPet

VPet 插件保持经典面板和离线玩法，不启用上述反馈桥。开发基线为 VPet 1.10.74，提交 `5a64ad2bf00a3f321227a26aa585bac6399b1a0e`；独立桌宠运行正常不等于 Steam 版宿主已验收。

1. 退出 VPet，找到 VPet 的程序目录。Steam 版可在游戏管理菜单中打开“浏览本地文件”。
2. 解压 ZIP，把里面的整个 `QiaoQiaoAI` 文件夹放到 VPet 程序目录下的 `mod` 文件夹中。不要再套一层同名文件夹。
3. 启动 VPet，在设置的 MOD 管理中找到“QiaoQiaoAI”（人工智障修理厂）并启用。代码插件未经宿主官方签名；点击宿主的“启用代码插件”，核对来源与代码后，在“是否启用 … 的代码插件？”提示中确认，然后重启 VPet。插件不会替你修改这个信任设置。
4. 右键桌宠，选择“自定 → 人工智障修理厂”。

正确的文件结构：

```text
VPet 程序目录/
└─ mod/
   └─ QiaoQiaoAI/
      ├─ info.lps
      ├─ plugin/
      │  ├─ QiaoQiaoAI.Plugin.dll
      │  └─ QiaoQiaoAI.UI.dll
      ├─ assets/
      │  ├─ skin.json
      │  ├─ spritesheet.png
      │  ├─ doubao.png
      │  ├─ doubao-skin.json
      │  ├─ doubao-spritesheet.png
      │  ├─ deepseek-reference.png
      │  ├─ deepseek-skin.json
      │  ├─ deepseek-spritesheet.png
      │  └─ quotes.json
      ├─ README.zh-CN.md
      ├─ LICENSE
      └─ NOTICE
```

安装包不携带 VPet 宿主 DLL。不要把其他版本的宿主 DLL 复制进插件目录，否则可能产生版本冲突。

## 操作

- Codex、豆包、DeepSeek 可随时切换；“工具箱”以九宫格列出九个图标，选中后仅显示对应图标，悬停查看操作提示。详见 [玩法表](../README.zh-CN.md#怎么玩)。
- 大多数工具按住约 0.35 秒后每 0.16 秒连击；便便蓄力约 0.6 秒后每 0.14 秒喷射。松手停止。
- “捏脸弹回”按住脸拖动，松手约 0.95 秒恢复。“软鞭抽打”选中后出现一条鞭子：抓住鞭柄来回甩，鞭身有惯性，扫中角色才计数；抓住停在空处不计数。长按角色可让同一条鞭子连甩，开始拖动后转为自由甩动。松手回摆，换工具或清理立即停止；粉红印记和脸红会消退。
- 纸团从准备投掷时就是不规则的皱纸团，带折面明暗、褶皱和阴影；印章直接在命中位置只印一个“滚”字，不显示回复卡或“答非所问”。
- 切工具、换脸、清理、失焦、失去鼠标捕获和退出均停止持续动作。“一键清理”同时清除红印与脸红，声音可单独开关。
- `assets/quotes.json` 含 24 条可配置的夸张 AI 自嘲台词；修改后重启生效。台词不等于真实反馈提示，表情不表示模型有真实感受。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| MOD 列表中没有插件 | 检查 `mod/QiaoQiaoAI/info.lps` 是否直接存在，避免重复套目录。 |
| 已启用但菜单没有入口 | 查看代码 MOD 的信任状态；信任并重启后再试，查看 VPet 日志。 |
| 提示角色素材缺失或配置错误 | 确认使用含素材的本地评审包，并检查 `assets/skin.json` 与 `spritesheet.png`；代码组件包本身不含图片。 |
| 桌宠不见了或任务栏里找不到 | 默认浮在右下角且不占任务栏。检查桌面；偏好普通窗口可用 `--classic` 启动。 |
| 没有常驻自动反馈，或仍显示“发送本轮反馈” | 完整更新至 v0.6.1 并使用 `Start-Resident.ps1`；旧窗口仍是旧流程，不带参数双击仍是玩具模式。 |
| 豆包脸按钮不可用，或仍显示旧的静态头像 | 检查 `assets/doubao-skin.json` 与 `doubao-spritesheet.png`；仅有旧版 `doubao.png` 不够。复制整个插件文件夹并重启，不能只换 DLL。 |
| DeepSeek 按钮不可用 | 检查 `assets/deepseek-skin.json` 与 `deepseek-spritesheet.png`，完整更新角色素材。 |
| 停手后已提交，聊天没有回复 | 先确认目标，等待已加载聊天检测队列；忙碌时等其正常处理，关闭或中断时打开/恢复。已入队不等于 AI 已回答。见 [反馈说明](FEEDBACK.zh-CN.md)。 |
| 显示未连接或无法确认目标 | 检查 Codex 已登录、CLI 版本兼容及状态文件；连接恢复后先按“重置”再敲打，旧的未绑定轮次不会补发给后来出现的聊天。 |
| 打了很多次仍只有一条反馈 | 这是预期行为：不按重置，本轮最多一条。要明确开始下一轮，先按“重置”；暂停、切工具、换聊天或重启程序都不会代替重置。 |
| 开了两个聊天，目标没跟着切窗口 | 路由按真人发消息时间，不按窗口焦点。向另一个聊天发消息后目标才会更新；正在进行的一轮仍发给第一下锁定的聊天。 |
| 与其他插件的界面重叠 | 先退出“人工智障修理厂”；记录同时启用的插件、宿主版本与显示缩放，按贡献指南提交复现步骤。 |
| Steam 版出现异常 | 记录 Steam 版本及日志；源码基线构建通过不等于 Steam 版已通过验证。 |

## 卸载

- 玩具版：关闭桌宠后删除其解压目录即可，没有后台服务或开机启动项。
- 技能版：只想收起时说“关闭人工智障修理厂”，或执行 `scripts/Stop-Resident.ps1`，保留安装和反馈记录。明确卸载时先执行 `scripts/Uninstall-Resident.ps1`；它清理本程序的旧登录启动项并请求正常退出，不强杀其他进程。确认退出后再删除技能目录；运行版本与反馈记录保留在 `%LOCALAPPDATA%\QiaoQiaoAI\resident`，需要时可自行清理。单独删除技能文件夹不会关闭正在运行的桌宠。
- 旧 v0.5.3 会话：原 `%LOCALAPPDATA%\QiaoQiaoAI\feedback` 目录独立保留，不被新安装自动清空。
- VPet 插件：先退出互动，在 MOD 管理中禁用并退出 VPet，再删除 `mod/QiaoQiaoAI`。宿主禁用要重启后生效，不会即时卸载代码。不要删除宿主存档或其他 MOD；玩法不额外修改养成数值，宿主自身循环仍正常运行。
