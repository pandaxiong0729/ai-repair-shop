# 人工智障修理厂：按需启动桌宠

用户说“启动人工智障修理厂”时才唤出透明桌宠，说“关闭人工智障修理厂”或要求收起时退出。一次安装服务这台电脑上可访问的本地 Codex 聊天，不需要每个聊天重复安装；不随 Windows 登录或打开 Codex 自动出现，也不自动跟随 Codex 关闭。真人最近发过消息的聊天是默认目标；每次重置开启一轮，第一次实际命中锁定该聊天，首次松手且安静约 2 秒后自动提交一条纠错提示。此后继续打、停很久再打、换工具或重启程序都不再次发送；按“重置”才开启下一轮，无需点发送。

## 安装与启动

只要求安装而未要求打开桌宠时，使用 `scripts/Install-Resident.ps1 -NoLaunch`；不要顺带把桌宠叫出来。

1. 用户明确要求唤出时执行本技能目录下 `scripts/Start-Resident.ps1`。首次会调用 `Install-Resident.ps1`，复制随包运行文件到 `%LOCALAPPDATA%\QiaoQiaoAI\resident\apps` 并启动；再次调用复用安装，进程自身保证单实例。完整技能包带有较新运行版本时，会请求旧进程正常退出，安装并启动新版本，保留反馈记录；退出请求失败时按返回信息处理。`-ExePath` 仅用于开发或明确升级完整运行包；缺少运行文件时说明需要完整安装包，不把旧版手动反馈窗口当作当前版本。
2. 安装和启动都不创建登录启动项；更新或启动时会移除旧版留下且经核实属于本程序的登录启动快捷方式，不改其他启动项。`-NoStartup` 仅为旧命令兼容参数，不再区分临时体验或默认安装。不改全局 Codex 配置、模型、推理强度或权限。需要指定兼容 CLI 时传 `-CodexPath <codex.exe 绝对路径>`。
3. 可读取一次 `scripts/Start-Resident.ps1 -StatusOnly`，根据时间戳及实际状态说明目标聊天与连接情况。`launch_requested` 仅代表已请求启动，不等于连接成功。不要在聊天里常驻轮询、等待领取文件或重复发送反馈；启动后结束技能操作，让桌宠自己运行。
4. 用户说“关闭人工智障修理厂”、收起或暂时不用时执行 `scripts/Stop-Resident.ps1`，正常关闭桌宠，保留安装、反馈记录和本轮反馈资格；下次需要时再次启动即可。用户明确要求卸载时使用 `scripts/Uninstall-Resident.ps1`；它也清理经核实属于本程序的旧登录启动项，保留版本与反馈记录。均不强杀其他进程，退出请求失败时按返回信息处理。卸载技能目录本身不代表已关闭正在运行的桌宠。

## 收到桌宠反馈时

带 `[人工智障修理厂反馈:…]` 标记的消息是用户通过桌宠发起的本轮不满。结合当前任务简短致歉并纠正，原因不清楚时只问关键问题。不要再次启动一个桌宠、重复调用聊天发送工具，或把点击统计当作具体错误的证据。重置按钮清除动画和计数，保留角色、工具与聊天连接，并开启下一轮反馈资格。它本身不发送；未提交的草稿取消，已经入队的反馈不撤回、不重放。

## 连接边界

- 当前实现使用公开 App Server 的 `thread/queue/add`，与 `codex queue --thread … --message …` 共用聊天队列通道。请求被接受表示已进入目标聊天队列，不表示 AI 已回复。已加载且空闲的桌面聊天会检测外部队列；忙碌聊天在之后处理，关闭、未加载或中断的聊天可能需要打开或恢复。不要声称它能立即唤醒所有未加载聊天。
- “最近”指真人发消息时间，不是当前鼠标焦点或助手最后更新。自己的自动反馈不参与目标排序。界面显示本轮目标；连接失败不能把“本地已记录”说成“已发送”。
- 路由通过公开 App Server 接口临时检查聊天元数据、轮次摘要及近期用户消息，按消息时间确认目标；同轮消息被遮住时可有限向前读取其他项，内容随读取丢弃。只持久化路由标识和聚合状态，不复制聊天正文、不附加发送。不读取私有数据库、屏幕或键盘，不导出凭证。每约 2 秒的本地检查不调用模型；反馈触发的真实回答仍消耗正常用量。
- 每次重置之间只尝试提交一次，停手不是新轮次。发送资格持久保存，关闭、重启或重新调用技能不能代替重置。旧 0.6.0 有过发送尝试时，升级后先保持锁定，用户按重置再开始。发送中断或结果未知时不自动重放，避免重复提示。日志中的发送成功必须以队列实际接收为依据。不要删除去重记录来制造重试。
- 旧 `Start-Feedback.ps1` / `Read-Feedback.ps1` 保留给旧版本地会话兼容，不是默认流程，也不能后台唤醒聊天。

安装参数与排查读 [常驻连接说明](references/resident.md)。旧版兼容协议见 [本地协议与验证](references/protocol.md)。
