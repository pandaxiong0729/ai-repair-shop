# 按需启动、连接与安装参数

适用于 0.6.1 起的 Windows 常驻版。完整运行文件在技能的 `assets/desktop` 中。纯源码包不含桌宠可执行文件和角色图片。

## 快速使用

在 Codex 里说“启动人工智障修理厂”，或在 PowerShell 执行技能目录下：

```powershell
./scripts/Start-Resident.ps1
./scripts/Start-Resident.ps1 -StatusOnly
```

桌宠只在用户要求时启动，不随开机、登录或打开 Codex 自动出现。安装和启动会取消旧版留下且经核实属于本程序的登录启动快捷方式，不更改其他程序的启动项。重复启动仍使用同一个实例；不用时说“关闭人工智障修理厂”，下次需要时再叫出来，不会自动跟随 Codex 关闭。

开发/升级使用：

```powershell
./scripts/Install-Resident.ps1 -ExePath 'C:\absolute\preview\QiaoQiaoAI.Preview.exe' -CodexPath 'C:\absolute\codex.exe'
```

整个完整运行目录会复制到 `%LOCALAPPDATA%\QiaoQiaoAI\resident\apps\<版本>-<内容指纹>`。同内容复用，升级生成新目录，不覆盖正在使用的 DLL。更新完整技能包后再次运行 Start，会识别包内较新的 DLL，先请求旧进程正常退出，再安装并启动新版本，保留反馈记录并取消本程序的旧登录启动项。退出请求失败时按返回信息关闭旧桌宠后重试；旧版本和未完成的临时安装目录保留。

## 参数

| 脚本 | 参数 | 用途 |
| --- | --- | --- |
| Start-Resident.ps1 | `-StatusOnly` | 只读 `status.json`，不启动、不发送。检查 `lastWrittenUtc`，旧快照不能证明程序仍在运行。 |
| Start / Install | `-ExePath` | 完整桌宠运行包中的 EXE，要求版本至少 0.6.1；旧 0.6.0 不支持每次重置之间只反馈一次。 |
| Start / Install | `-CodexPath` | 指定实际支持公开 `queue` 命令的 Codex CLI。 |
| Start / Install / Stop / Uninstall | `-DataRoot` | 指定数据目录；默认使用当前用户 LocalAppData。测试时使用独立目录。 |
| Start / Install | `-NoStartup` | 旧命令兼容参数；当前所有安装和启动都不创建自启，并取消本程序的旧登录启动项。 |
| Install | `-NoLaunch` | 只安装，不开启桌宠，也不创建登录启动项。 |

## 反馈如何到达聊天

1. 通过公开 App Server 接口取得聊天元数据及近期用户消息，按真人消息时间排序。聊天自己产生的反馈前缀不算真人活动；后台模型运行不抢走目标。
2. 按“重置”开启本轮资格，首次实际敲中桌宠时锁定聊天。连续点击、长按和拖鞭共用这一轮，首次松手且约 2 秒没有后续操作时封存。此后不论暂停多久或继续打多少下，都不再发送；再次按重置才开新轮。
3. 发送前按首次命中时间重新核对真人消息；本地保存本轮 ID 和聚合状态后，调用公开 App Server 的 `thread/queue/add` 一次，与 `codex queue --thread <目标ID> --message <固定纠错提示>` 共用队列通道。固定提示包含唯一反馈标记，不把角色台词或逐次敲打记录发送给 AI。
4. 发送资格会跨程序重启保留。旧 0.6.0 有过发送尝试时，升级后先保持锁定，按重置再开始。重置本身不发送，尚未提交的草稿丢弃；已入队消息不能撤回。
5. 队列接收与 AI 回复是两件事：空闲且已加载的聊天通常在约 10 秒量级检查队列；正在工作的聊天排在之后；关闭、未加载或中断的聊天可能需要打开或恢复。界面不能用“AI 已收到并纠正”替代“已入队”。

命令不可用、退出失败或连接断开时显示相应失败/未知结果。未知结果不自动重试。不要用修改私有数据库、模拟键盘发送、常驻聊天轮询或重放旧反馈替代公开连接。

路由会临时读取近期消息、摘要和时间戳；同轮较早真人消息被新消息遮住时有限向前查找，可能短暂经过其他消息或工具项，内容随读取丢弃。只保存路由标识与聚合状态。常驻程序约每 2 秒检查本地接口，不调用模型；真正反馈触发的回答仍消耗正常用量。

## 关闭或卸载

```powershell
./scripts/Stop-Resident.ps1
```

关闭脚本通过已安装程序的 `--resident-stop` 请求正常退出，保留安装、版本、本地反馈记录及本轮反馈资格。返回 `stopRequested` 表示已请求退出，不是强杀；若 `closePetToExit` 为 true，请关闭桌宠。明确卸载时执行 `Uninstall-Resident.ps1`，它也清理经核实属于本程序的旧登录启动项；不会删除 Codex 聊天、技能、配置或其他启动项。

## 旧版兼容

`Start-Feedback.ps1` 和 `Read-Feedback.ps1` 是 0.5.3 的手动会话文件方案，保留用于旧窗口和验证，不再作为新技能的默认路径。新版本不需要在聊天里不断调用 Read-Feedback，也没有“发送本轮反馈”步骤。
