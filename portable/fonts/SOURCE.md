# AI Repair UI Regular

AI Repair UI is an application-specific subset of **Noto Sans CJK SC Regular 2.004**, © 2014–2021 Adobe. The project distributes this modified font under the SIL Open Font License 1.1. [License](OFL.txt)

The source is the static Simplified Chinese OpenType font from the Noto CJK repository, commit `523d033d6cb47f4a80c58a35753646f5c3608a78`. [Original font](https://github.com/notofonts/noto-cjk/blob/523d033d6cb47f4a80c58a35753646f5c3608a78/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf) · [Original license](https://github.com/notofonts/noto-cjk/blob/523d033d6cb47f4a80c58a35753646f5c3608a78/LICENSE)

The subset keeps printable ASCII and the characters used in the desktop controls, messages, and built-in dialogue. Two locally drawn symbols supply the drag handle (U+283F) and menu indicator (U+25BE). The modified family's name is **AI Repair UI**. Its copyright and license metadata are retained in the font.
